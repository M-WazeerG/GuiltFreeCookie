# Cookie reference images

Put your inspiration images here. Codex uploads them to Higgsfield before it generates
anything. Give each reference one job:

| File | Controls |
| --- | --- |
| `angle-reference.jpg` | Camera angle, crop, how much of the frame the cookie fills |
| `lighting-reference.jpg` | Light direction, softness, highlights |
| `texture-reference.jpg` | Thickness, surface cracks, gooey or chewy interior |
| `inspiration-board.jpg` | Overall mood and photographic quality |

If a role has no file, Codex falls back to the existing brand cut-outs in
`frontend/public/img/` for angle, crop, lighting and isolation only.
